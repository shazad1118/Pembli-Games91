# یاری پێمبڵێ - Pêmbilê Game

## فایلەکان (Files)

1. **index.html** - پەڕەی سەرەکی
2. **style.css** - شێواز و دیزاین
3. **script.js** - کۆدی جاڤاسکریپت

## چۆن بەکارهێنان (How to Use)

### ١. دانانی وێنە (Background Images)
فایلەکانی PNGی خۆت بنێرە لە هەمان فۆڵدەر:
- `bg1.png` - پەڕەی یەکەم (سەرەتا)
- `bg2.png` - پەڕەی دووەم (مێنیو)
- `bg3.png` - پەڕەی سێیەم (ناوی یاریزانەکان)
- `bg4.png` - پەڕەی چوارەم (یاری)

### ٢. دانانی دەنگ (Audio Files)
فایلەکانی MP3ی خۆت بنێرە لە هەمان فۆڵدەر:
- `music.mp3` - گۆرانی باکگراوەند
- `click.mp3` - دەنگی دوگمە
- `timerend.mp3` - دەنگی کات تەواو بوو

### ٣. کردنەوەی یاری
فایلی `index.html` بکەرەوە لە بڕاوسەر (Chrome, Firefox, Edge...)

## تایبەتمەندیەکان (Features)

✅ ٦ پەڕەی جیاواز
✅ سیستەمی ناوی یاریزان (٢-٤ کەس)
✅ تایمەر (١-٣ خوولەک)
✅ ١٥٠+ وشەی کوردی
✅ ڕێکخستنی گرافیک (١٤٤، ٢٧٠، ٤٠٠)
✅ دەنگ و گۆرانی ON/OFF
✅ فێرکاری
✅ دووبارە یاری
✅ کۆنترۆل بە کیبۆرد (Space, Arrow keys)
✅ localStorage بۆ هێشتنەوەی ڕێکخستن

## ڕێکخستنەکان (Settings)

- **گرافیک**: ١٤٤ (پێکسل)، ٢٧٠ (ئاسایی)، ٤٠٠ (بەرز)
- **کات**: ١، ٢، ٣ خوولەک
- **دەنگ**: چالاک/ناچالاک
- **گۆرانی**: چالاک/ناچالاک

## کۆنترۆڵەکان (Controls)

| دوگمە | کردار |
|-------|--------|
| Space / → | وشەی ڕاست |
| ← / ↓ | وشەی ئەمانە |
| ESC | وەستان/بەردەوامبوون |

## یاری (How to Play)

1. ناوێکی یاریزانەکان بنووسە (٢-٤ کەس)
2. دەستپێکردن داگرە
3. وشەکان بخوێنەوە بەبێ ئەوەی بڵێیت
4. کات تەواو بوو ئەو کەسەی نۆرەیە بەرە!
